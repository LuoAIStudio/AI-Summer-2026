# Day 18：面向对象 —— 封装（私有属性/方法）与继承（派生 / 重写 / super）

## 今日主题
- 封装：私有属性、私有方法（`__` 前缀）。
- 继承：子类复用父类的属性与方法（三大特性之二）。
- 派生与继承的传递性（继承像树一样层层传递）。
- 方法重写（override）与 `super()`。

## 私有属性与私有方法（封装）
- 属性/方法名前加 `__` 即私有，如 `self.__age`。
- 私有属性/方法不能在**外部**直接访问（`xiaohua.__age` 会报错），但可以在**类内部**使用（如 `secret()` 里访问 `self.__age`）。
- 私有并非绝对私有：用 `对象._类名__属性名`（如 `xiaohua._Women__age`）仍能访问，这叫"名字改写"（name mangling）；私有方法同理。
- 封装是面向对象三大特性之一。

## 继承（三大特性之二）
- 语法 `class Dog(Animol)`：括号里是**父类（基类）**，括号外是**子类（派生类）**。
- 子类自动继承父类的所有属性与方法（`Dog` 继承 `Animol` 的 `run()` / `eat()`）。
- 意义：**相同代码的复用**。

## 派生与继承的传递性
- `Dog` 是 `Animol` 的派生类。
- 继承有**传递性**，像一棵树一样层层传递：`XiaoTianQuan(Dog)` 能用 `run()`（Animol 的）、`bark()`（Dog 的）、`fly()`（自己的）。

## 方法重写（override）与 super()
- 父类方法不满足需求时，在子类定义**同名方法**覆盖它。
- `super().方法()` 调用**父类**里被覆盖的那个方法。
- 例：`Dog` 重写 `run()` 打印"跑跑跑"，再 `super().run()` 调用 `Animol` 的"跑"。

## 父类的私有属性/方法与继承
- 子类一般**不能直接**调用父类的私有属性/方法。
- 想用的话，借助父类的**公有方法/属性当媒介**，间接访问。

## 容易踩的坑
1. **重复定义同名类会覆盖**：文件里出现了两次 `class Dog(...)`，第二次会**覆盖**第一次的 `Dog`，导致第二个 `Dog` 不再有 `bark()`。类名重复定义要留意。
2. **私有属性的"伪私有"**：`__age` 只是被改写成 `_类名__age`，并不是真的藏起来，外部仍可通过 `_类名__属性名` 访问到。
