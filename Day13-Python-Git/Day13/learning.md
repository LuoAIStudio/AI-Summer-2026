# 二、变量的引用与内存地址

## 1. 数据存在内存中，变量是"引用"

- 每个数据在内存中占据一个位置，这个位置叫**地址**
- 变量不是数据本身，而是**访问这个地址的引用**

```python
a = 1
print(id(a))   # 查看 a 引用的数据地址
print(id(1))   # 同一个数据，地址相同
```

- `id()` 函数可以查询数据在内存中的地址
- id 函数只注重数据在哪里，并不注意变量的位置

# 三、函数传参的本质

## 1. 实参传递的是"地址"

```python
def test(num):
    print("函数内部 %d 的地址是 %d" % (num, id(num)))
    result = "hello"
    print("%s 的地址是 %d" % (result, id(result)))
    return result

a = 1
c = test(a)   # 实参 a 把数据地址传给了形参 num
```

- 实参传递的是**数据地址**，让形参 `num` 引用这个地址
- 函数的**返回值**同样返回的是数据的地址
- 没有变量接收返回值也不会报错

# 四、可变类型与不可变类型

## 1. 可变类型：列表、字典

```python
b = [1, 2, 3, 4]
print(id(b))
b.append(5)     # 用方法修改，地址不变
print(id(b))

b = [1, 2, 3, 4, 5]   # 赋值会让变量引用新的地址
print(id(b))
```

- **用方法修改**（append 等）不会改变列表在内存中的地址
- **重新赋值**会改变变量的引用

## 2. 不可变类型：字符串、数字、元组等

- 目前学过的可变类型只有**列表**和**字典**

# 五、哈希与字典的 key

## 1. 什么是哈希

```python
print(hash("hello"))
print(hash(1))
```

- `hash()` 对**不可变数据**生成一个"特征码"，像指纹一样具有唯一性

## 2. 字典的底层原理

- 字典会对 **key 进行哈希**来保存数据，这就是字典的底层处理
- 所以 **key 必须是不可变类型**（字符串、数字、元组）
- **key 不能是列表/字典**（可变类型）
- value 可以是任意数据

# 六、局部变量与全局变量

## 1. 作用域与生命周期

- **局部变量**：函数内部定义，生命周期 = 函数执行期间，函数结束就被系统回收，所以其他函数不能用
- **全局变量**：函数外部定义，所有函数都可以使用

```python
g_num = 10  # 全局变量放在代码最前面

def demo1():
    global num   # 把 num 声明为全局变量
    num = 100

def demo2():
    print("demo2 --> %d" % num)

demo1()
demo2()
```

## 2. 注意事项

- 全局变量定义位置要在使用它的函数**前面**（Python 逐行解释，避免用到未定义的变量）
- 全局变量命名可以加前缀（如 `g_`），避免与局部变量重名
- 函数内部**默认赋值不会影响全局变量**，需要修改必须用 `global`
