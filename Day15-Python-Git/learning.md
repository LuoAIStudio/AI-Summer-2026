# 二、递归函数

## 1. 什么是递归

- 递归函数 = 函数内部调用自己
- 可以类比 while 循环（`sum_number(num-1)` 和 `i+=1` 的作用一样）
- **必须有递归出口**（用 if 判断，满足条件就 return），否则陷入死循环

```python
def sum_number(num):
    print(num)
    if num == 1:
        return          # 递归出口
    sum_number(num - 1) # 自己调用自己

sum_number(4)   # 输出：4 3 2 1
```

## 2. 递归的两种模式（重要）

| | 模式 A：只做副作用 | 模式 B：需要返回值 |
|---|---|---|
| 目的 | 每层打印/执行操作 | 每层算出结果传回 |
| 返回值 | 不需要（None 也行） | **必须 return** |
| 调用写法 | `sum_number(num-1)` | `return num + sum_numbers(num-1)` |

- 模式 A 的打印发生在"下降"途中（调用之前），每层自己打印自己，不需要别人传结果
- 模式 B 的结果只能靠"上升"时传回来，所以每一层都必须 return

## 3. 递归求和（核心）

- 递推公式：`sum(n) = n + sum(n-1)`，出口 `sum(1) = 1`

```python
def sum_numbers(num):
    if num == 1:
        return 1                    # 递归出口
    temp = sum_numbers(num - 1)     # 假设它已经算好 1 加到 num-1
    return temp + num               # 再加上自己

print(sum_numbers(100))   # 5050
```

## 4. 今天我踩的坑：为什么返回了 None？

错误写法：

```python
def sum_numbers(nums):
    num1 = 0            # bug1：每层调用都重新归零，无法累积
    num1 += nums
    if nums == 1:
        return num1
    sum_numbers(nums - 1)   # bug2：调用了但没写 return 接住结果
```

原因分析：

- **bug1**：`num1` 是局部变量，每层递归都是新的、从 0 开始，3 和 2 永远加不到一起
- **bug2（关键）**：`sum_numbers(nums-1)` 虽然调用了函数、内层也算出了结果，但没写 `return` 接住，结果被丢弃 → 每层都返回 None，最外层只拿到 None

结论：**递归传值 = 每一层都必须 return，像接力棒一样把结果传回最外层。**

# 三、面向对象入门（OOP）

## 1. 类与对象

- **类 = 设计图纸**（定义这个种类有什么属性和方法）
- **对象 = 图纸生产出来的东西**（实例）
- 一个类可以创建多个对象
- 类命名用**大驼峰命名法**（首字母大写，如 `Cat`）

## 2. 类 = 属性 + 方法

- **属性**：描述类的特征（一般是名词）—— 如狗的毛色是黄色
- **方法**：类能做的动作（一般是动词）—— 如狗碰到家人摇尾巴

## 3. 定义类并创建对象

```python
class Cat:                 # 定义类
    def eat(self):         # 封装方法，self 代表"谁调用我"
        print("%d岁的小猫要吃鱼" % self.age)

tom = Cat()                # 创建对象：tom 引用了 Cat 类在内存中的地址
tom.age = 1                # 给对象添加属性
tom.eat()                  # 输出：1岁的小猫要吃鱼

huahua = Cat()
huahua.age = 2
huahua.eat()               # 输出：2岁的小猫要吃鱼
```

- 同一个类可以打造多个对象，对象之间互不影响

## 4. 关于 self

- **谁调用方法，self 就指向谁**（tom 调用 eat，self 就是 tom）
- 方法里用 `self.属性名` 访问该对象的属性

## 5. 对象在内存中的地址

- 每个对象在内存中有不同的存储位置
- `print(对象)` 会显示十六进制地址；`id()` 获取地址，`%x` 转成十六进制输出

```python
a = id(tom)
print("%x" % a)    # 输出十六进制地址
```

## 6. dir() 查看内置属性和方法

- `dir(对象)` 能查看这个对象（变量、函数、数据）的所有内置属性与方法
- 输出里能看到 `__init__`、`__str__` 等双下划线方法（明天继续学）

# 五、遇到的问题

（已解决）递归求和返回 None：

- 现象：`result = sum_numbers(3)` 结果是 None
- 原因：递归调用的返回值没被 return 接住（每层丢弃）+ 局部变量每层归零
- 解决：`return temp + num` 每一层都接住再传回去
