# 二、__str__ 魔术方法（新知识）

## 1. 没有 __str__ 时，print(对象) 显示什么？

- 默认打印内存地址：`<__main__.cat object at 0x...>`
- 看不出这个对象是什么，很丑

## 2. 有了 __str__ 之后

```python
class cat():
    def __init__(self, color):
        self.color = color
    def __str__(self):
        return "我是小猫"    # 必须返回字符串！

xiaobai = cat("白色")
print(xiaobai)   # 输出：我是小猫（不再是内存地址）
```

- **规则**：`__str__` **必须返回字符串**（return 一个 str），否则报错
- **作用**：`print(对象)` 时自动调用 `__str__`，用它返回的内容代替内存地址

# 三、__del__ 深入理解

## 1. 触发时机：引用数归 0 时

- 对象在内存中有一个"引用数"= 有几个变量指向它
- 引用数变成 0（最后一个引用被删）→ 对象销毁 → 触发 `__del__`

## 2. 两种触发情况

| 情况 | 触发时机 |
|------|----------|
| 显式 `del 变量`（删掉最后一个引用） | **立刻**触发 |
| 不删，程序结束 | 解释器统一清理，**最后**触发 |

## 3. 关键理解（今天最重要的概念）

- **销毁是 Python 自动做的**，`__del__` 可有可无，只是"临终广播"
- `del` 删的是"引用（变量名）"，不是直接销毁对象
- 多个变量指向同一个对象时，删一个引用对象还在，**不触发** `__del__`

```python
def __del__(self):
    print("%s的小猫将要离开了" % self.color)
```

> 比喻：对象是房间，变量是钥匙，del 是还钥匙。房间只有所有钥匙都还完才被拆除，__del__ 是拆房前的广播。

# 四、__init__ 巩固

- 创建对象的**瞬间**自动执行，每个对象创建时执行一次
- 用来初始化属性（`self.color = color`）
- 不需要手动调用（和 `eat()` 不一样）

# 五、综合练习：小明爱跑步（项目.py）

```python
class person:
    def __init__(self, name, weight):
        self.name = name
        self.weight = weight
    def __str__(self):
        return "%s的体重是%.1f" % (self.name, self.weight)
    def eat(self):
        print("%s爱贪吃" % self.name)
        self.weight += 1
    def run(self):
        print("%s爱跑步" % self.name)
        self.weight -= 0.5

xiaojie = person("小杰", 60)
xiaojie.eat()   # 60 + 1 = 61
xiaojie.run()   # 61 - 0.5 = 60.5
print(xiaojie)  # 小杰的体重是60.5
```

- 体会：一个类把"属性（体重）+ 方法（吃/跑）"**封装**在一起
- 方法可以修改自己的属性（`self.weight`）
- 不同对象调用方法互不影响（各自维护自己的属性）

# 七、遇到的问题

（已解决）体重显示 60 而不是 60.5：

- 现象：`__str__` 里用 `%d` 格式化体重，60.5 显示成 60
- 原因：`%d` 是整数格式化，小数被**截断**（不是四舍五入，60.9 也会变 60）
- 解决：改用 `%.1f`（保留 1 位小数）显示 60.5
- 经验：**凡是可能带小数的数，别用 `%d`**（体重、金额、平均分用 `%s` 或 `%.1f`）
