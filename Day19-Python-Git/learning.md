# Day 19：面向对象 —— 多继承 / MRO / 多态 / 类属性 / 类方法与静态方法

## 今日主题
- 多继承：一个类同时继承多个父类。
- MRO：方法解析顺序（`__mro__`）。
- 多态：面向对象第三大特性。
- 类属性、类方法（`@classmethod`）、静态方法（`@staticmethod`）。

## 多继承
- 语法 `class C(B, A)`：括号里写多个父类，这叫**父类列表（继承列表）**，不是元组。
- 子类 `C` 同时拥有 `B` 和 `A` 的方法（`c.test()`、`c.dome()` 都能用）。
- 意义：一个类可以复用多个父类的能力（但能用单继承解决就不要用多继承，避免混乱）。

## MRO（方法解析顺序）
- 多个父类有**同名方法**时，按 MRO 顺序取**继承列表中靠前的父类**的方法。
- `类.__mro__` 可以查看查找顺序，例：`C -> B -> A -> object`。
- Python 用 **C3 线性化**算法确定这个顺序。

## 新式类
- 以 `object` 为基类的叫**新式类**；Python 3 中所有类**默认继承 object**，不用显式写。
- `dir(对象)` 可以查看对象的所有属性与方法。
- 「经典类 vs 新式类」是 **Python 2 的历史概念**，Python 3 里已经全是新式类，这个区别不用记。

## 多态（三大特性之三）
- 子类**重写**父类方法后，**不同子类对象调用同一个方法会产生不同结果**。
- 例：`Dog.game()` 打印"爱玩飞盘"，`XiaoTianQuan.game()` 打印"飞了起来"；`Person.game_with_dog(dog)` 传入不同的狗对象，`dog.game()` 就输出不同结果。
- 关键：`game_with_dog` 里写的是 `dog.game()`，**不用关心传入的是哪种狗**，Python 会自动调用对应的 `game()`。

## 类属性
- 在类内部用**赋值语句**定义的属性（如 `count = 0`），属于**类本身**，所有实例共享。
- 实例查找属性的顺序：**先找自己的实例属性，没有再去类里找**。
- 用途：记录与整个类有关的数据（如"一共创建了几个工具"）。

## 类方法（@classmethod）
- 用 `@classmethod` 装饰，第一个参数是 `cls`（表示**类本身**）。
- 通过**类名调用**，专门用来处理类属性。
- 例：`Tool.show_count()` 里用 `cls.count` 打印创建的工具数量。

## 静态方法（@staticmethod）
- 用 `@staticmethod` 装饰，**既不引用实例属性，也不引用类属性**。
- 通过**类名调用**，相当于"放在类里的普通函数"，只是逻辑上归这个类管。

## 容易踩的坑
1. **多继承别滥用**：父类多、又有同名方法时，查找顺序容易搞混，能单继承就单继承。
2. **类方法 vs 静态方法**：类方法第一个参数是 `cls`（能访问类属性）；静态方法没有 `cls`/`self`（啥属性都不访问）。
3. 小拼写：代码里的 `dome` 应为 `demo`（演示）——不影响运行，留意即可。
